# 公网和局域网联机

## 默认公网联机

打开国内 COS 入口，点「联机」建房、分享链接即可。默认先通过现有中继开局，同时在后台尝试浏览器直连。直连可用后，状态与操作走无序、无重传通道；事件、商店指令和房间控制仍可靠经过中继。直连中断立即回退中继，不需要重新建房。角落显示当前「直连」或「中继」。

公网直连使用公共 STUN 发现地址，没有部署 TURN，严格 NAT 或防火墙下不保证成功。STUN 不转发游戏数据；可通过构建参数 `VITE_STUN_URLS` 指定逗号分隔的 STUN 地址，设置为空字符串则不使用外部 STUN。房主在大厅点「使用中继」可以关闭本房间的自动直连。

## 浏览器局域网直连

所有人打开国内 COS 入口或 GitHub Pages。房主点「联机」→「局域网」→「建房」，把房间链接或二维码发给同一网络的玩家；朋友打开链接，点准备，房主开始。双方都只需要浏览器，不需要安装 Node.js 或启动程序。

建房、房间名单与浏览器连接信息仍通过现有联机服务交换；游戏状态与操作走浏览器之间无序、无重传的数据通道，事件、商店指令和完整存档走独立可靠有序通道。不配置 STUN / TURN，不使用外部穿透或转发服务。直连未完成时不能开局，也不会悄悄把游戏数据改走公网中继。

这不是完全离线模式：建房服务必须可达，页面首次加载也需要联网。当前测试域名可能解析为私网，Chrome 需要允许页面访问本地网络；异地朋友可能无法访问测试服务。访客 Wi-Fi、公司网络隔离或防火墙可能阻止设备之间直连。浏览器和房主页面保持前台运行，所有玩家使用最新版。

游戏消息超过单条通道长度时分片，接收时重组；发送队列有大小上限，连接失败会重新协商。房主切换时重建连接，游戏沿用原有恢复流程。可运行 `node tools/direct-check.mjs` 验证大消息、重连及房主迁移；通过实际中继的完整双浏览器回归用 `GAME_TEST_TRANSPORT=rtc node tools/net-comfort.mjs --cloud`，当前私网测试域名还需 `GAME_TEST_ALLOW_LOCAL_NETWORK=1`。该权限仅用于自动化测试，应用本身不绕过浏览器限制。

## 独立内网程序（可选）

公网玩法：打开 COS 或 Pages，点「联机」，建房后分享链接。玩家无需在同一个 Wi-Fi。自动直连不成功时游戏数据经过公网中继。

局域网玩法由一台电脑同时提供网页和中继，其他电脑或手机打开内网网址即可。数据只经过这台电脑，不经过公网 Java 服务或 Redis。公网房间与局域网房间分开，房间码不能跨中继使用。

### 房主启动

电脑安装 Node.js 24 或更新版本，下载源码后在项目目录执行：

```sh
npm ci
npm run lan
```

首次安装依赖需要联网。命令检查类型、构建游戏到独立的 `dist-lan/`，启动网页（5181）和中继（5300）。现有公网构建 `dist/` 不受影响；局域网构建明确使用内网中继，不会继承公网的构建地址。

终端打印类似下面的网址，把其中内网 IP 的地址发给玩家：

```text
http://192.168.1.10:5181/?online=&network=lan&relay=ws%3A%2F%2F192.168.1.10%3A5300
```

房主也打开这个地址，建房后复制房间链接或展示二维码。加入的玩家不需要安装 Node.js。电脑保持唤醒和程序运行，Ctrl+C 关闭网页和中继。房间保存在内存中，关闭程序后失效。

### 连接与端口

所有设备需要能在局域网中互相访问。同一个 Wi-Fi 通常满足，但访客网络、无线设备隔离或公司网络策略可能阻断连接。系统防火墙需要允许网页与中继的端口，不要将端口映射到公网。终端可能显示多个网卡地址，选择玩家能够访问的那个；`localhost` 只适合房主自己使用。

HTTPS Pages 不能直接连接不加密的内网 WebSocket。局域网玩家应打开上述 HTTP 内网网址，页面和中继一起由房主电脑提供，不要从 Pages 页面填写一个 `ws://` 地址。

端口被占用时可指定：

```sh
LAN_PORT=5183 LAN_RELAY_PORT=5301 npm run lan
```

Windows PowerShell 用 `$env:LAN_PORT="5183"` 与 `$env:LAN_RELAY_PORT="5301"` 设置，再执行 `npm run lan`。网页和中继端口必须不同。生成的分享链接会保留自定义端口；退出游戏回到标题后也会保留当前中继。

### 验证

自动验证可在启动后执行：

```sh
GAME_TEST_URL=http://localhost:5181 GAME_TEST_RELAY=ws://localhost:5300 node tools/net-comfort.mjs
```

该验证使用两份真实浏览器页面，检查商店选择、跨普通波、两次再战及队友移动。它不能代替多台设备的 Wi-Fi 试玩，也不能证明公网抖动已经消失。
