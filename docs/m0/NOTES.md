# M0 手感原型说明（2026-11-09）

## 怎么玩

- 本机 `http://localhost:5180/`，手机连同一 Wi-Fi 打开 `http://<Mac 的局域网 IP>:5180/`，横屏。
- 电脑：WASD / 方向键移动，空格（或 J）放神通，阵亡后按 R 重来。
- 手机：按住屏幕任意处拖动是摇杆，右下角是神通按钮。
- `?bot` 让机器人自己打（截图、自测用）；`?art` 回到画风试画场景；`?hair=backsingle|backtwin|round` 换发髻。

## 里面有什么

- 乾坤圈自动瞄准最近的敌人，飞出去再折返，往返各能打一次；飞得越远越大（5 → 7 → 9 像素三档手绘），判定半径跟着放大。
- 回响兵按时间越刷越密；第 20、40 秒……各来一次「回响合围」；第 25 秒起每 22 秒一只精英「回响校尉」（2 倍大、紫甲红眼、带血条）。
- 神通「三头六臂」：击杀充能（45 只充满，精英一只顶四分之一），放出时以自身为中心冲击一圈，再向八方各掷一枚乾坤圈。
- 灵石（经验）掉落、靠近被吸走；本原型还没有升级和商店，那是 M1。
- 第二轮（按用户试玩反馈）：
  - 空气墙换成**魔气**：出了仙台边缘越往外越慢、掉血越快（按最大气血百分比，不受无敌时间影响），外沿是硬边界；镜头始终居中；屏幕四周泛紫、角色泛紫、紫色侵蚀数字、低沉嗡鸣。
  - 回响兵换成长矛 + 魂披风；精英「回响校尉」原生手绘，背插四面靠旗、持偃月刀。
  - 新增远程怪「鬼火术士」（第 35 秒起，约占刷怪 8%，最多 10 只）：保持距离，举杖蓄力 0.45 秒（碎光往杖头聚拢预警）后放一团慢速鬼火；乾坤圈能把鬼火打散。
  - 命中音换成圆润的金属「咚」+ 低频闷响，去掉尖锐的高频；神通改为耗尽整条「真气」，约 80 次击杀充满。

## 打击感（全部只在表现层，不停模拟）

| 事件 | 反馈 |
|---|---|
| 乾坤圈命中 | 受击闪白、击退、2–3 粒碎光、白色伤害数字（暴击金色大号）、短促命中音（随机 ±1 半音，最短间隔 28ms） |
| 击杀 | 魂散（天青雾 + 上升的魂光）、轻微震屏（累积有上限）、古筝拨弦，连斩越多音越高（五声音阶） |
| 精英击杀 | 命中停顿 75ms、中等震屏、大团魂散、和弦 + 低频轰鸣 |
| 受伤 | 角色泛红、屏幕四边红光、命中停顿 60ms、震屏、气血条闪白 |
| 神通 | 命中停顿 120ms、强震屏、白闪、三道冲击波、60 粒火星、残影、「三头六臂」大字、铜锣 + 轰鸣，战鼓让位 |
| 拾取 | 铃声，连续拾取音高往上爬 |
| 战况 | 战鼓随同屏敌人数变密 |

用户口径：人物和武器身上都不要光圈；乾坤圈只在飞行时落一两粒金色碎光。

## 数值基线

`node tools/balance.ts 20 180`（机器人 20 局、每局最多 180 秒）：存活中位数 117 秒，击杀中位数 579，神通 10 次，同屏峰值约 170。
本原型没有成长，难度一直上升，所以每局都会结束；M1 加上升级和商店后重新调。

## 自查方式

- `npm test`：模拟模块的 6 个单元测试（确定性、命中击杀、拾取、神通、受伤无敌、刷怪曲线）。
- `node tools/shot-feel.mjs "http://localhost:5180/?bot"`：机器人跑一局，在关键时刻截图，记录帧率、敌人数和控制台报错。
